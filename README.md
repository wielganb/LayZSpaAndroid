# Lay-Z-Spa Miami – Android v0.4

GitHub → CodeMagic → APK.

v0.4 adds a responsive island-style UI, five selectable languages (Polski, English, Deutsch, Français, Español), larger temperature and control cards, configurable ESP8266 host/port, and a local Spa Settings section for pump profile and HydroJet mode.

The existing WebSocket command protocol is preserved. Pump-profile/HydroJet mode selections are stored locally; no undocumented hardware commands are invented.

Default ESP8266 host: 192.168.1.40
WebSocket port: 81
