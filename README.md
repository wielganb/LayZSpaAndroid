# Lay-Z-Spa Miami – Android v0.3

GitHub → Codemagic → APK project.

v0.3 adds a polished island/card UI, responsive minimum-sized control areas, English/German language switching, and editable ESP8266 host + WebSocket port. The connection settings are saved locally. Host can be an IP address or a DNS hostname.

Default host: 192.168.1.40
Default WebSocket port: 81
WebSocket URL: ws://HOST:PORT/

The original ESP8266 WebSocket command numbers and JSON state fields are preserved.
